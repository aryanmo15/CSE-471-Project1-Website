# Turntable Circuit · CSE 471 Project 1

Website files for a project on scratching synthesis and audio effects, by Aryan Moparti and Michael Biggar.

## Publish on GitHub Pages

1. Open the **CSE-471-Project1-Website** repository on its `main` branch.
2. Use **Add file → Upload files**. Upload **all files in this folder**. All files are deliberately placed at repository root so the GitHub web uploader can upload them in one selection.
3. Commit the changes, then check the Pages deployment under **Actions**.
4. Open https://aryanmo15.github.io/CSE-471-Project1-Website/ and test all three players and score download links.

Do not upload the containing folder as a subfolder. `index.html`, `styles.css`, the other HTML files, audio, and XML files must sit alongside each other at the repository root.

The published files are HTML/CSS, three MP3s, three original WAVs, three XML score files, and this README. The complete compiled Windows source project stays in the separate C++ repository.

## Verified from submitted project ZIP

- Final composition: `selection.wav`, 79.3 sec, 44.1 kHz, 16-bit stereo
- Effects demo: `effects_demo.wav`, 13.25 sec, 44.1 kHz, 16-bit stereo
- Scratching demo: `scratch_demo.wav`, 14.4 sec, 44.1 kHz, 16-bit stereo
- Final XML score: 618 notes, 32 measures, 100 BPM
- Nonzero effect sends in final score: chorus 113, reverb 260, flanger 81, ring 20
- Scratching methods configured in final score: baby, chirp, scribble, transform, orbit

AI assistance was used in composing the musical selection, as disclosed on the website.
