Component 02 / Audio processing

Effects processor

Four independent DSP effects and controllable sends, applied to each stereo audio frame as the synthesizer runs.

Component owner: Aryan Moparti

Effects implemented

The processor supports dry passthrough, individual wet buses and a combined output. Each effect retains its state between audio frames.

Effect 01

Chorus

Two delayed copies of the input move slowly in time, using sinusoidally varied delay lengths near 22 milliseconds. Different phase offsets in the stereo channels produce a wider sound.

Effect 02

Reverberation

Four feedback comb filters simulate repeated reflections. Two all-pass filters diffuse the reflections to create a reverb tail distinct from a single echo.

Effect 03

Flanging

A short modulated delay is mixed with the current signal and fed back into the delay. The shifting delay creates moving cancellations and resonances.

Effect 04

Ring modulation

The incoming sample is multiplied by a sinusoidal carrier at 74 Hz. The resulting frequency sidebands give the output a metallic character.

Routing and sample streaming

All effects are parallel so each note can specify a different amount of each effect.

Per-note routing

Each instrument generates a stereo frame. The frame is multiplied by five independently set levels: dry, chorus, reverb, flanger and ring. The values are accumulated into five stereo buses.

Settings on a <note> override defaults from its enclosing <instrument>.

Bounded memory

CSynthesizer::Generate() invokes CEffects::Process() once for each audio frame. The effects use compact circular-delay and feedback buffers rather than loading the entire final selection into RAM.

A 2.5-second processing tail lets delayed sound decay after the last instrument note.

<instrument instrument="ScratchInstrument" dry="0.7" reverb="0.3">
  <note measure="1" beat="1" duration="2"
        sample="are-you-ready.wav" method="baby"
        chorus="0.5" flanger="0.25" />
</instrument>

How the effects component meets the rubric

For each point level, this table identifies the C++ classes, the signal processing performed, and how the XML score demonstrates it. These are implementation claims rather than awarded grades.

PointsCriterionHow our implementation addresses it
10Component passes audioIn CSynthesizer::Generate(), each active CInstrument produces left and right samples. The sequencer multiplies those samples by the instrument's EFFECT_DRY send and accumulates them in the dry bus. CEffects::Process() starts its output from that dry bus. With dry="1" and all four wet sends at zero, the original scratching audio passes straight through without intentional alteration.
20One effectThe first fully implemented processor is CChorusEffect. Its Process() method writes each input frame into a stereo circular buffer and reads back two delayed copies using CStereoDelayLine::Read(). Those delays oscillate around 22 ms by ±6 ms at 0.65 Hz. Linear interpolation makes the changing read position smooth; a different phase offset for the right channel widens the result. The XML chorus send determines how much of a note enters this processor.
30Three effectsThe second effect, CReverbEffect, combines four parallel feedback comb delays (about 30–45 ms) and then passes their sum through two all-pass filters per channel. The feedback produces a decaying tail; all-pass diffusion makes it sound less like separate echoes. The third effect, CFlangerEffect, moves a much shorter delay between approximately 0.7 and 5.3 ms at 0.28 Hz, mixes it with the live sample, and recirculates part of the delayed sample using 0.45 feedback. These produce different audible effects from chorus, meeting the three-effect requirement.
40Controllable effects sendsCInstrument::LoadEffectSends() reads five attributes: dry, chorus, reverb, flanger, and ring. The default is dry audio at 1.0 with all wet sends at zero. Instrument-level settings apply to all its notes unless a particular <note> supplies an override. Values are constrained to the 0–2 range in Instrument.cpp. During CSynthesizer::Generate(), every active note contributes to each effect bus according to its chosen send level, so effects can be turned on, off, or combined without changing the underlying scratching algorithm.
50Four effectsThe fourth processor, CRingModEffect, multiplies both audio channels by a 74 Hz sine wave. This modulation creates a metallic character different from the three time-delay-based effects. CEffects holds all four processors for the duration of playback and calls each one on every stereo frame, even if its input bus is silent, preserving reverb and delay tails. It combines the wet returns with the dry bus using fixed return gains (chorus 0.75, reverb 0.85, flanger 0.70, ring 0.65), then bounds the normalized output to [−1, 1]. The combined note in effects_demo.score sends audio to all four at once.

The final selection includes chorus sends on 113 notes, reverb on 260, flanging on 81, and ring modulation on 20. These counts indicate score usage, while the instructor evaluates audible quality and whether all grading requirements are demonstrated.

Implementation reference: Effects.h defines the buses and persistent effect classes; Effects.cpp implements the DSP processors; Instrument.cpp parses the sends; and Synthesizer.cpp performs routing, mixing, and the final 2.5-second effects tail.

What happens to one audio frame

This is how the effects stay compatible with the project's streaming requirement.

1. Route note samples

The scratching instrument outputs left and right sample values. For every active note, the synthesizer multiplies each channel by the XML dry and effect-send levels, then adds the results to the corresponding buses. Defaults come from the instrument tag; note attributes take precedence.

2. Process and mix

The effects processor advances its circular buffers, modulation phases, and feedback filters once per frame. It mixes the wet returns with dry audio, checks for non-finite values, and bounds the output to the expected normalized range. A 2.5-second tail allows delayed effects to decay after the last note.
