Project overview

An offline synthesizer written in C++ with a score-driven sequencer, a scratching instrument and a four-effect processor.

01 / Format

XML score

Measures, beats and note attributes tell the synthesizer when to play and which effects to apply.

02 / Sound

Scratching synthesis

Recorded audio is played through a model of record motion and cross-fader behavior, controlled per note.

03 / Output

Streaming stereo

The system produces one audio frame at a time and writes 44,100 Hz, 16-bit stereo output.

System architecture

Each stage contributes to the final audio frame. Effects maintain small delay buffers rather than storing the full song.

Score file format

The XML score fully specifies performance timing and allows instrument notes to override default effect send levels.

Timing and note parameters

  • bpm, beatspermeasure control musical timing.
  • measure, beat, duration schedule and time each note. Duration is measured in beats.
  • sample, method, startPosition, speed, cycles, stroke configure recorded sound and scratch motion.
  • dry, chorus, reverb, flanger, ring set independent routing gains. Notes can override their instrument defaults.

Example

<score bpm="120" beatspermeasure="4">
  <instrument instrument="ScratchInstrument"
              dry="0.8" reverb="0.2">
    <note measure="1" beat="1"
          duration="2" sample="are-you-ready.wav"
          method="baby" chorus="0.5" />
  </instrument>
</score>
